# Code of Conduct

This is a small project maintained by one person in his spare time. This file is short on purpose:
it says what is expected here, and it does not describe a committee that does not exist.

## What is expected

Assume the other person is acting in good faith and is short on time. Criticise the change, not the
person who wrote it. Say what is wrong and what would be right instead — "this is broken" costs the
reader an evening, "this writes the layer offsets before the thumbnail, so the table points past the
data" costs them ten minutes.

Nobody here is obliged to answer you. A pull request may sit for weeks, or be declined. That is not
disrespect; it is one person's calendar.

## What is not acceptable

Harassment, insults, and personal or political attacks. Sexualised language or imagery. Comments
about someone's identity — nationality, religion, gender, sexuality, disability, age — in any
register, including as a joke. Publishing anyone's private information.

Persisting after being asked to stop is itself the problem, whatever the original subject was.

## Who decides

The maintainer does, alone, and there is no appeal beyond him. He may edit or delete comments, close
issues, and block accounts. He will say why when it is not obvious.

He is bound by this file too. If he is the problem, the honest answer is that this project has no
mechanism for that, and your remedy is [GitHub's own abuse
reporting](https://github.com/contact/report-abuse) and the fork rights the licence gives you.

## Reporting something

If it can be discussed in public, open an issue or a discussion and say so plainly. If it cannot,
open a [private vulnerability report](https://github.com/vvvlladimir/Encrust/security/advisories/new)
— it is the one private channel this repository has, and it reaches the maintainer alone.

## Scope

Issues, pull requests, discussions and commit messages in this repository, and anywhere someone is
representing this project.
