# 0179. A plate file is TOML, read by the command line alone

- **Status:** Accepted
- **Date:** 2026-10-03

## Context

The command line sliced one model, and since ADR 0178 a whole project the window saved. A
script building a plate — a farm queue, a test rig — has neither a window to save a project
nor a way to give each model its own turn, wall or supports through flags that apply to
every model at once. It needs a plate it can write as text.

## Decision

`encrust slice plate.toml` reads a plate file: an optional `printer`, `resin`,
`layer_height_mm` and `arrange`, and one `[[model]]` table per model with its `path`
(relative to the file) and optional `rotate`, `scale`, `position`, `supports` preset and
`hollow = { wall_mm, mode }`. Unknown keys are refused. A flag wins over the file, the file
over the profiles. `arrange` and a `position` cannot be mixed. The format is in
`docs/cli.md`; it lives in `encrust-cli`, which takes `toml` for it, and nothing below the
command line knows it exists.

## Consequences

A plate of several differently shaped models is one text file, diffable and generated by
anything. Drain holes, channels, relief and infill are not in it yet: each is a key added
when someone needs it, with the same flag-over-file rule. A second reader of the format —
the window importing a plate file — would move it out of `encrust-cli`, into its own
module of `core-engine` beside the project.

## Alternatives considered

### Only projects

The window is the one writer of a project, and a JSON manifest of face-indexed patches is
not something to write by hand. A script would have to generate it through a library.

### JSON, or the project's manifest with fewer fields

JSON has no comments and is unpleasant by hand; TOML is already how every profile is
written, so a user who has edited a printer profile has seen the syntax.

### The option that won, and what it costs

A second plate format beside the project, with its own small schema to keep in step with
the flags. Each key it grows is one more place a setting can come from.
