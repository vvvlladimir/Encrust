# Russian: style

How `assets/i18n/ru.ftl` is written. The terms are in [`ru-glossary.md`](ru-glossary.md);
how a catalogue works is [`../i18n.md`](../i18n.md). The rules are in Russian, for whoever
translates.

## Тон и обращение

- Аудитория — владельцы фотополимерных принтеров, от новичков до опытных. Тон спокойный,
  разговорный, без канцелярита («осуществить», «данный», «в рамках», цепочки родительных).
- Обращение на «вы» со строчной буквы; «ты» нет. В инструкциях — повелительное наклонение
  («Выберите принтер»), в описаниях и статусах — безличные и активные формы.
- «Пожалуйста» опускается. Не обвинять: «Не удалось прочитать», а не «Вы выбрали неверный файл».
- Программа не говорит о себе в первом лице: «Чтение шрифтов…», не «Читаю шрифты».

## Формы строк

| Тип | Форма | Пример |
|---|---|---|
| Кнопка, пункт меню | инфинитив | Сохранить, Копировать, Сделать полой |
| Название инструмента, вкладки, раздела | существительное | Починка, Измерение, Поддержки |
| Процесс (прогресс) | отглагольное существительное | Нарезка, Создание полости |
| Статус после действия | что произошло | Профиль поддержек сохранён |
| Ошибка (строчная, встаёт после контекста) | «не удалось …» / что не так | не удалось открыть { $path } |
| Подтверждение | короткий вопрос | Удалить? Сбросить все клавиши? |
| Подсказка, описание | полное предложение с точкой | |

- Регистр как в предложении: заглавная только у первого слова и имён собственных.
- Короткие подписи, кнопки и заголовки — без точки; строки ошибок с маленькой буквы, как в
  английском, — их приклеивают к контексту окна.
- Щелчок по модели — «щёлкните»; кнопка — «нажмите»; «кликните» не пишем. Модификаторы:
  «Shift + щелчок», «Cmd + Shift + щелчок»; названия клавиш латиницей, как на клавиатуре.

## Пунктуация и типографика

- Кавычки «ёлочки»: названия кнопок и полей в тексте («Построить поддержки») и подставленные
  имена, когда без кавычек ломается согласование («Удалить «{ $name }»?»).
- Многоточие — один символ «…», без пробела перед ним.
- Тире «—» с пробелами; диапазон «0,3–1» — короткое тире без пробелов.
- Число и единица — через неразрывный пробел (U+00A0): `{ $value } мм`. Знак градуса
  и `{ $value }%` пишутся слитно, как в английском.
- Буква «ё» пишется везде.
- Десятичная запятая — только в прозе; числа из программы приходят с точкой (`../i18n.md`).

## Подстановки и числа

- Падеж подставленного слова проверяется по месту, где его вставляют: `scope-*` стоит
  в винительном («Нарезает на слои выбранную модель»).
- Счётчик — всегда через `one`/`few`/`many`; если форма не нужна, фраза строится через
  двоеточие: «граней без площади: { $count }».
- Имя модели неизвестного рода не согласуется с глаголом: «Разрезано: { $name }»,
  «{ $name } — починено: …».

## Сокращения

Только общепринятые: ч, мин, с, мм, мкм, мл, г, МБ, Н, МПа, «пикс.», «макс.», «выкл.».
Слово, которое не помещается, заменяется более коротким синонимом, а не обрубается.
