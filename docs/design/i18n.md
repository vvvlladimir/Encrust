# The window in other languages

Why Fluent and how the language is chosen: ADR 0300. This page is how to translate, how to
change a string so every language follows, how much room a language needs, how to add a
language, and what a string in the code has to look like.

## Translating

Each language is one file, `assets/i18n/<code>.ftl`, compiled into the binary. English,
`en.ftl`, is the source; a message a translation does not have shows in English, so a
translation can be finished a piece at a time.

```sh
cargo xtask i18n ru >> assets/i18n/ru.ftl   # what Russian lacks, as English to translate
cargo test -p encrust-app --lib i18n        # every catalogue parses and agrees with English
cargo run -p encrust-app                    # Settings → Appearance → Language
```

The groups (`## panels/inspector/cut.rs`) name the file a message is shown from, which is
where to look for its context. Translate the text after `=` and keep the id. A message may
read only the `{ $arguments }` its English reads, in any order, or none of them.
Russian has its own style and glossary: [`i18n/ru-style.md`](i18n/ru-style.md),
[`i18n/ru-glossary.md`](i18n/ru-glossary.md). The `i18n-editor` agent (`.claude/agents/`)
holds changed messages to them; a Stop hook asks for it while a change is unpassed.

Plurals select on a number argument. `[one]`, `[few]`, `[many]` and `[other]` are the
language's own categories, which for Russian are 1 and 21, 2 to 4, 5 to 20 and the rest
(`[one]` is also 21, so a variant with no number in it, such as "yesterday", is `[1]`):

```
layers-bands =
    { $count ->
        [one] { $count } полоса
        [few] { $count } полосы
       *[many] { $count } полос
    }
```

A unit is a message of its own (`unit-mm`, `value-mm = { $value } mm`), translated once.
Numbers arrive formatted, with a point for the decimal mark: the number fields parse only
that. A `scope-*` message is set into a tooltip as its `{ $scope }`, so its case has to fit
the sentences that take it.

## Writing English

English is written for its translators: one term a concept, whole sentences with arguments,
no idioms, a comment where the use is not in the words. The rules: [`i18n/en-style.md`](i18n/en-style.md).

## Changing a string

A translation is matched to English by key alone, so nothing notices a translation that
no longer says what its English says. In the change that touches English:

- **New message:** English only is enough; it shows in English until translated, and
  `cargo xtask i18n <code>` lists it.
- **Same meaning, new wording** (a typo, a shorter word): keep the key; the translations stand.
- **New meaning** (another action, another value, another argument): a new key, the old
  one deleted from every catalogue, so each language shows English rather than something
  false. An argument added or removed is always a new meaning.
- **Deleted message:** deleted from every catalogue; the test fails on one left behind.
- **New term:** added to the English column of every `i18n/<code>-glossary.md`.

## Room for every language

A translation runs up to 40 % longer than English, more in a short label, and a few words
of German or Russian may be one long word. So a button, tab, chip or card takes its width
from the column or its text, never from a size fitted to the English; a name longer than
its room is cut with an ellipsis and read whole on hover (`ui-standards.md`, Length). A
new or reworded label is looked at in the longest language the window has (Russian today),
Settings → Appearance → Language, before the change is done; a translation that does not fit
is shortened in that catalogue, not the layout widened for it.

## Adding a language

Read first: this page, [`i18n/en-style.md`](i18n/en-style.md), the Voice, Names and Length
rules of `ui-standards.md`, ADR 0300, and an existing language's style and glossary
(`i18n/ru-style.md`, `i18n/ru-glossary.md`) as the template for yours.

1. Check the script: the window draws IBM Plex (`ui::fonts`), which covers Latin and
   Cyrillic. Another script needs its font added there first; egui lays out no
   right-to-left text, so such a language waits on that.
2. Write `i18n/<code>-style.md` and `i18n/<code>-glossary.md` before translating: the form
   of address, buttons, progress, errors, quotes, units and plural forms, then one word for
   each term the English column lists.
3. `cargo xtask i18n <code> > assets/i18n/<code>.ftl` and translate it, keeping each group's
   order. A plural has the language's CLDR categories, the default `*[other]` last.
4. Add a variant to `Language` in `crates/encrust-app/src/i18n.rs` with its primary subtag
   as its serde name and `code`, its own name for itself, its `langid!` and its `index`,
   and `include_str!` the file beside the others. The system's language is matched by the
   primary subtag, so `pt-BR` finds `pt`.
5. `cargo test -p encrust-app --lib i18n`, then walk every screen in the language for
   overflow and agreement, and add the language to `docs/features.md`.

## Writing a string in the code

Everything the window shows goes through `tr!("area-what", name = value)`, the key a
literal, with its English in `en.ftl` under the group of the file that shows it. A sentence
is one message with arguments, never pieces joined in the code: word order and agreement
differ between languages. A count goes in as a number, so that a plural can select on it.
Reuse a message only where the meaning is the same everywhere (`common-cancel`,
`unit-mm`); the same English word in two places is two messages. The test fails on a key
the code names that English lacks, and on an English message no code names.

## What stays English

- The command line and its man pages, and everything under `docs/`.
- The error text of the core crates. The window's own context line over it is translated:
  "не удалось открыть plate.goo: invalid magic".
- Names a project or a printer stores: the support groups `Default` and `Islands`, which
  the code finds by name, and what a printer reports, such as its print stage.
- The bug report, which is read by whoever fixes the bug.
- Key names in shortcuts (Ctrl, Shift, Esc), as the keyboard prints them.
