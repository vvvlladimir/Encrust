# The window in other languages

Why Fluent and how the language is chosen: ADR 0300. This page is how to translate, how to
add a language, and what a string in the code has to look like.

## Translating

Each language is one file, `assets/i18n/<code>.ftl`, compiled into the binary. English,
`en.ftl`, is the source; a message a translation does not have shows in English, so a
translation can be finished a piece at a time.

```sh
cargo xtask i18n ru >> assets/i18n/ru.ftl   # what Russian lacks, as English to translate
cargo test -p encrust-app --lib i18n        # every catalogue parses and agrees with English
cargo run -p encrust-app                    # Settings → General → Language
```

The groups (`## panels/inspector/cut.rs`) name the file a message is shown from, which is
where to look for its context. Translate the text after `=` and keep the id. A message may
read only the `{ $arguments }` its English reads, in any order, or none of them.

Plurals select on a number argument. `[one]`, `[few]`, `[many]` and `[other]` are the
language's own categories, which for Russian are 1 and 21, 2 to 4, 5 to 20 and the rest
(`[one]` is also 21, so a variant with no number in it, such as "yesterday", is `[1]`):

```
layers-bands =
    { $count ->
        [one] { $count } полоса
        [few] { $count } полосы
       *[many] { $count } полос
    }
```

A unit is a message of its own (`unit-mm`, `value-mm = { $value } mm`), translated once.
Numbers arrive formatted, with a point for the decimal mark: the number fields parse only
that. A `scope-*` message is set into a tooltip as its `{ $scope }`, so its case has to fit
the sentences that take it.

## Adding a language

Add the file, a variant to `Language` in `crates/encrust-app/src/i18n.rs` with its primary
subtag, its own name for itself and its `langid!`, and `include_str!` it beside the others.
The system's language is matched by the primary subtag, so `pt-BR` finds `pt`.

## Writing a string in the code

Everything the window shows goes through `tr!("area-what", name = value)`, the key a
literal, with its English in `en.ftl` under the group of the file that shows it. A sentence
is one message with arguments, never pieces joined in the code: word order and agreement
differ between languages. A count goes in as a number, so that a plural can select on it.
Reuse a message only where the meaning is the same everywhere (`common-cancel`,
`unit-mm`); the same English word in two places is two messages. The test fails on a key
the code names that English lacks, and on an English message no code names.

## What stays English

- The command line and its man pages, and everything under `docs/`.
- The error text of the core crates. The window's own context line over it is translated:
  "не удалось открыть plate.goo: invalid magic".
- Names a project or a printer stores: the support groups `Default` and `Islands`, which
  the code finds by name, and what a printer reports, such as its print stage.
- The bug report, which is read by whoever fixes the bug.
- Key names in shortcuts (Ctrl, Shift, Esc), as the keyboard prints them.
